# NEON CASES v2 — Telegram-бот без сайта

## Что внутри
- Один кейс «Неоновый», стоимость открытия — 1 билет.
- Ранги и шансы: F 50%, E 25%, D 15%, C 7%, B 2.5%, A 0.5%.
- Игровая ценность предметов: F=1, E=2, D=5, C=12, B=30, A=100 условных единиц. Это внутренняя игровая оценка, не реальные деньги.
- Анимация открытия через редактирование сообщения Telegram.
- Билеты выдаёт/списывает только Telegram ID администратора.
- Баланс, инвентарь, история, журнал выдач, список пользователей.
- Данные хранятся в SQLite.

## Запуск на Android через Termux
1. Установи Termux из F-Droid или официального источника.
2. Распакуй архив в папку на телефоне и скопируй файлы проекта в доступную папку, например `~/neon-cases`.
3. В Termux:
   ```bash
   pkg update
   pkg install python
   cd ~/neon-cases
   pip install -r requirements.txt
   ```
   Если архив распакован в Download, можно сначала разрешить доступ к файлам: `termux-setup-storage`, затем перейти в нужную папку `/storage/emulated/0/Download/...`.
4. Создай бота у @BotFather командой `/newbot` и скопируй токен.
5. Узнай свой Telegram ID. Можно запустить бота после временной установки ID, либо использовать команду `/id` после настройки.
6. В Termux задай секреты и запусти:
   ```bash
   export BOT_TOKEN='ТОКЕН_ОТ_BOTFATHER'
   export ADMIN_IDS='ТВОЙ_TELEGRAM_ID'
   python bot.py
   ```
   Для нескольких админов: `ADMIN_IDS='123456,987654'`.
7. Открой своего бота в Telegram и нажми Start.

## Админ-команды
- `/give USER_ID КОЛИЧЕСТВО [примечание]` — выдать билеты.
- `/take USER_ID КОЛИЧЕСТВО` — списать билеты.
- `/balance USER_ID` — проверить баланс.
- `/users` — последние пользователи.
- `/ticketlog` — последние начисления/списания.

Пользователь должен сначала нажать Start у бота, чтобы попасть в базу. Узнать свой ID можно командой `/id`.

## Запуск на компьютере или сервере
Установи Python 3.10+ и зависимости `pip install -r requirements.txt`, затем задай `BOT_TOKEN` и `ADMIN_IDS` как переменные окружения и запусти `python bot.py`. Интерфейс Telegram доступен на телефонах и компьютерах. Чтобы бот работал постоянно даже при выключенном телефоне, запусти его на хостинге с постоянным диском. При использовании Render проверь наличие persistent disk: без него SQLite-файл может теряться при пересоздании среды.

## Безопасность и ограничения
- Никогда не отправляй токен бота посторонним и не загружай его в GitHub.
- Не удаляй `casebot.sqlite3`, иначе потеряются балансы и инвентарь.
- На Android процесс может быть остановлен системой; отключи оптимизацию батареи для Termux.
- Анимация — последовательность обновлений сообщений Telegram, не браузерная 3D-анимация.
- Все предметы виртуальные и не передаются между пользователями.
